# Currency Converter

Một mini project xây dựng ứng dụng **chuyển đổi tiền tệ** giữa các đơn vị phổ biến:

- `EUR`
- `USD`
- `VND`
- `AUD`

Ứng dụng được phát triển bằng **HTML, CSS, JavaScript thuần** nhằm luyện tập các kiến thức nền tảng về:

- DOM Manipulation
- Event Handling
- Object Mapping
- Form Validation
- UI Styling
- Tư duy tách file theo cấu trúc dự án cơ bản

## Mục tiêu dự án

Dự án được thực hiện như một bài tập mini project sau buổi học, với mục tiêu:

- Xây dựng giao diện chuyển đổi tiền tệ trực quan, dễ sử dụng
- Thực hiện logic chuyển đổi giữa nhiều loại tiền tệ
- Tổ chức mã nguồn theo cấu trúc tách biệt:
  - `index.html`
  - `style.css`
  - `main.js`
- Làm quen với quy trình xây dựng một web app nhỏ từ đầu

## Tính năng chính

- Nhập số tiền cần chuyển đổi
- Chọn loại tiền tệ nguồn
- Chọn loại tiền tệ đích
- Chuyển đổi qua lại giữa:
  - EUR
  - USD
  - VND
  - AUD
- Kiểm tra dữ liệu đầu vào hợp lệ
- Hiển thị kết quả chuyển đổi
- Giao diện đơn giản, hiện đại, dễ mở rộng thêm tính năng

---

## Công nghệ sử dụng

- **HTML5**: xây dựng cấu trúc giao diện
- **CSS3**: thiết kế giao diện, bố cục, màu sắc và trải nghiệm người dùng
- **JavaScript (Vanilla JS)**: xử lý logic chuyển đổi, thao tác DOM và sự kiện
